What & Why

Add a "Note" mode to Quick Generate so GMs can jot something down mid-session without leaving the panel — and optionally push it straight into the current session's raw notes. This fills the gap between generating content and capturing live thoughts.
Done looks like

    A "Note" chip appears in the Quick Generate kind selector alongside NPC, Encounter, etc.
    Selecting it replaces the AI prompt/stream area with a simple freeform textarea — no AI generation, just plain text input.
    Two action buttons appear below:
        "Add to session notes" — appends the note text (with a timestamp prefix) to the current session's dmRawNotes. Only shown when there is an active (in_progress) session for the current campaign. Shows a confirmation tick on success.
        "Copy" — copies the note text to clipboard.
    If no in-progress session exists, only the Copy button shows (and a subtle hint that there's no active session to append to).
    The note text is cleared after a successful "Add to session notes" action (with a brief success message).

Out of scope

    Saving notes as a standalone entity type in the campaign library.
    AI-assisted note expansion or summarisation.
    A persistent note history inside Quick Generate.

Steps

    Add "note" kind — Add note to the kind union type and the kind chip list in the QuickGenerate component. Render a plain <textarea> instead of the streaming result area when this kind is active.
    Detect active session — On mount (when campaignId is present), query whether an in_progress session exists for the campaign. Expose this as local state.
    Append-to-session API call — Wire the "Add to session notes" button to PATCH /api/campaigns/:campaignId/sessions/:sessionId/notes/append (or the closest existing endpoint). Implement the server endpoint if it doesn't exist: it appends the note text (prefixed with a timestamp) to dmRawNotes on the session record.
    Success / empty states — Show a ✓ confirmation on success, clear the textarea. Show a muted hint when no in-progress session exists.
