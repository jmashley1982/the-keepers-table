I want to expand the "Session Zero — Campaign Planning" section of my app (currently just a single freeform textarea on the Session Log page) into a full guided campaign setup suite. Keep the existing dark "candlelight" theme, gold accent colors, and serif heading style consistent with the rest of the app.

Replace the single textarea with a tabbed or accordion-based Session Zero workspace containing these modules:

1. CAMPAIGN PITCH BUILDER
- Structured fields: campaign title, elevator pitch (2–3 sentences), genre, expected length (one-shot / short arc / long campaign), and a "what this campaign is NOT" field.
- Tone sliders: grim ↔ heroic, gritty ↔ cinematic, episodic ↔ serialized, combat-heavy ↔ roleplay-heavy. Store slider values as part of the campaign record.
- An "AI Assist" button that takes whatever the GM has entered (even a rough sentence) and generates or refines the full pitch. Use my existing AI generation infrastructure (same as Quick Generate).
- A "shareable pitch" view: a clean read-only page or modal the GM can share with players via link.

2. SAFETY TOOLS
- Lines & Veils manager: a pre-populated checklist of common sensitive topics (violence against children, sexual content, torture, harm to animals, body horror, phobias like spiders/drowning, real-world religion, etc.), each markable as "Line" (never appears), "Veil" (fade to black), or "OK". GM can add custom topics.
- Anonymous player input: generate a share link where players can submit their own lines & veils WITHOUT their names attached. Merge all submissions into a combined "Table Boundaries" summary that shows the strictest setting for each topic. The GM must never see which player submitted what.
- A content rating selector (e.g., PG / PG-13 / R) and a free-text "session tools we use" field (X-card, Script Change, etc.).

3. TABLE CHARTER / PLAYER AGREEMENTS
- Editable template covering: scheduling & attendance, missed-session policy, PvP rules, loot splitting, phones at the table, rules disputes, and homebrew policy.
- Provide 2–3 starter templates (casual table, serious long-form campaign, online/Discord table) the GM can pick and edit.

4. WORLD-BUILDING CANVAS
- Structured entry lists instead of freeform text: Factions, Regions/Locations, Major NPCs, Pantheon/Powers, Central Conflict, Secrets & Mysteries.
- Each entry has: name, one-line summary, expandable detail text, and an "Expand with AI" button that generates fuller detail consistent with the campaign pitch and tone sliders.
- IMPORTANT — data flow: entries created here should connect to the rest of the app. A Major NPC created in Session Zero should be saved so it appears in the campaign's Library; Factions should be available as tags/references for Bestiary entries and NPCs; Regions should be linkable from Maps. If full integration is complex, at minimum store these in shared campaign-level tables that other sections can query, and add a visible link/reference on each entry.

5. PLAYER CHARACTER COORDINATION
- A party overview pulling from my existing Players section: list each player's character concept/class/role, and flag niche overlap (e.g., two healers, no frontliner).
- Bond generator: AI generates suggested relationships/bonds between PCs based on their concepts ("Character A owes Character B a debt — decide what for").
- Hook weaver: AI reads the character concepts plus the world-building canvas and suggests 2–3 ways to tie each character's backstory into the campaign's factions and secrets.

6. SESSION ZERO AGENDA
- A checklist run-of-show for the actual session zero meeting: present pitch → safety tools → table charter → character creation → set opening scene. Each item is checkable with a notes field. Pre-populate with a sensible default agenda but let the GM add/remove/reorder items.

GENERAL REQUIREMENTS
- All fields auto-save as the user types, matching the existing auto-save behavior.
- Add a progress indicator showing how complete the Session Zero setup is (e.g., "4 of 6 modules started").
- Everything must be scoped per-campaign, tied to the current campaign ID like the rest of the app.
- Migrate my existing Session Zero notes: put the current textarea content into a "Legacy Notes" field inside the World-Building Canvas so nothing is lost.
- Mobile-responsive.
- Build this incrementally and confirm the data model with me before writing the UI: start with the schema changes, then Module 1 and 2, then check in with me before continuing to 3–6.
